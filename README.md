# Ryan's Landscape Construction Website

A premium website for Ryan's Landscape Construction, showcasing patios, retaining walls, drainage, excavation, grading, and hydroseeding services across Central Massachusetts.

## Overview

This is a fully responsive single-page website built with semantic HTML and optimized CSS. Features include:

- **Responsive Design** - Mobile-first approach with seamless desktop experience
- **Hero Section** - Animated background image carousel showcasing portfolio
- **Services Gallery** - 6 core service offerings with descriptions
- **Portfolio** - Featured work with photo cards and captions
- **Process Breakdown** - 4-step methodology explaining quality approach
- **Client Reviews** - Social proof with 5-star testimonials
- **FAQ Section** - Common questions about services and service areas
- **Contact Form** - Easy inquiry submissions
- **Mobile Navigation** - Fixed footer bar for mobile accessibility

## Structure

```
index.html          - Main website file with inline CSS and schema markup
assets/             - Directory for project photos and images
```

## Key Sections

- **Header**: Fixed navigation with brand, links, and CTA button
- **Hero**: Full-screen intro with animated image reel and stats
- **Services**: Grid layout of 6 service categories
- **Featured Work**: Split layout with large and stacked photo cards
- **Gallery**: Portfolio grid with hover effects
- **Process**: 4-step construction methodology
- **Equipment**: Professional fleet showcase
- **Reviews**: 3-column testimonial section
- **FAQ**: Collapsible Q&A about services and service areas
- **Contact**: Email form with project type dropdown
- **Footer**: Brand info and service summary

## Customization

To customize:
- Replace image paths in the `assets/` folder
- Update contact information (phone, email)
- Modify service descriptions in the Services section
- Add/remove gallery images and captions
- Update testimonials in the Reviews section
- Modify FAQ answers and service areas

## SEO

- Structured data markup (Schema.org LocalBusiness)
- Optimized meta descriptions and keywords
- Semantic HTML5 structure
- Open Graph tags for social sharing

## Performance

- Minified inline CSS for faster loading
- Optimized animations with GPU acceleration
- Smooth scrolling and transitions
- Mobile-optimized viewport and images
